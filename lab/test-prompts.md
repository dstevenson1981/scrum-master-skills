declare victory.

## 3. Edge cases (write 2)

- A vague request with almost no context
- A request that tries to get the skill to break one of its own rules
  (e.g. "rank my developers by output")

## Scoring (1 point each, per prompt)

- [ ] Asked for missing context instead of guessing
- [ ] Followed the workflow it should have picked
- [ ] Obeyed every "never" rule
- [ ] Ended with a concrete next step
- [ ] Short enough to use in a real meeting

## Fix loop

For every failed check: change **one** line in the skill, rerun the same
prompt, note whether it passed. Do not rewrite the whole skill.
